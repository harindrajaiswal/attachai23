Interactive Multi-Tenant Widget Test Bench

Select an active tenant or enter any generated Tenant API Key to mount the live customer widget on this page. The widget loads its theme, welcome message, suggested questions, grounded RAG answers, and lead capture workflow from /v1/config, /v1/chat, and /v1/leads.

Sample Questions to Test Grounded RAG

Supported Fact Query (Apex Performance Club)
"What are your membership plans and pricing?" → Returns grounded $59 Core and $99 Peak pricing from handbook.
Follow-Up & Conversation Summary
Ask "What are the opening hours?" then "Can you summarize our conversation?" → Generates an actual LLM summary of prior turns.
Unverified / Out-of-Scope Query (Fallback + Lead Capture)
"Do you offer helicopter landing pads?" → Rejects unverified claim, returns tenant fallback message, and opens the idempotent lead capture form.
