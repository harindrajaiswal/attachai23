This archive contains ONLY the newly added and modified files required to apply
the three requested upgrades to an existing Orbit AI codebase:

  1. Upgrade 1: Advanced Intelligent Response Engine with Multilingual Multi-Query RAG
  2. Upgrade 2: Persistent Conversation Memory & Multi-Turn Context Resolution
  3. Upgrade 3: Premium Dynamic Chat Widget UI & Assistant Message Action Toolbar
     (Like, Dislike with optional reason, Copy, Share + Database Persistence)

All file paths in this archive preserve the exact original repository directory
structure so you can extract it directly over your project root:

  unzip -o orbit-ai-upgraded-files.zip -d /path/to/your/orbit-ai

[ADDED] CHANGES.txt
  - This manifest documenting all newly added and modified files, database
    migration steps, and upgrade summaries.

[ADDED] supabase/migrations/0002_message_feedback.sql
  - Idempotent PostgreSQL / Supabase SQL migration creating the
    `public.message_feedback` table with `UNIQUE (tenant_id, message_id)`,
    foreign keys to `tenants`, `conversations`, and `messages`, indexes on
    `(tenant_id, created_at DESC)`, `(conversation_id)`, and `(message_id)`,
    automatic `updated_at` trigger, and Row-Level Security (RLS) policy.

[ADDED] tests/test_upgrades.py
  - Automated unit and integration test suite (37 new tests) covering:
    * Category A (18 tests): Intelligent intent routing (GREETING,
      GENERAL_CONVERSATION, SUMMARY_REQUEST, AMBIGUOUS, OUT_OF_SCOPE,
      KNOWLEDGE_QUESTION, FOLLOW_UP_QUESTION), Hindi/Hinglish/Urdu/English
      multilingual RAG against English documents, synonym expansion, RRF
      multi-query deduplication, Scenario B expanded search, strict grounding,
      and removal of customer-facing "Unverified Answer" / internal status labels.
    * Category B (10 tests): Multi-turn conversation memory, English & Hinglish
      pronoun/entity resolution, rolling conversation summaries, conversation
      reset/deletion, cross-tenant memory isolation, and retry messageId
      idempotency.
    * Category C (9 tests): Assistant message feedback persistence (Like,
      Dislike with/without reason, in-place toggle update without duplicates),
      feedback restoration on message reload, cross-tenant & role validation,
      and widget UI / CSS capabilities.
